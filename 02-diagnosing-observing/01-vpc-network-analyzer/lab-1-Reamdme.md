Objective: In this lab, you will use Amazon VPC Network Access Analyzer to identify resources that are accessible from the internet. This analysis will help verify that only resources requiring legitimate internet access are exposed through internet gateways, enhancing your security posture.

1. From the AWS Console click in the search bar in the top left corner. Type VPC in the services search bar. Select VPC from the list.
